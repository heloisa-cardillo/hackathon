# Plataforma Integrada de User Research & Governança de Insights

Protótipo desenvolvido durante o **Hackathon Itaú — Jornada de Agentes**, com o objetivo de transformar pesquisas com usuários em insights relevantes para a tomada de decisão das squads.

*Este repositório contém alguns dos testes desenvolvidos durante o hackathon.*

## Sobre o projeto

A plataforma utiliza o conceito de Inteligência Artificial e agentes para apoiar o processo de User Research, desde a definição dos objetivos da pesquisa até a organização das respostas e a geração de insights.

A proposta busca reduzir a dependência de pesquisas desatualizadas, conectando as necessidades dos clientes às decisões de produto.

## Funcionalidades

- **Criação de pesquisas:** definição de objetivos e configuração de formulários.
- **Templates de pesquisa:** estruturação de perguntas conforme os objetivos.
- **Coleta de respostas:** organização das informações obtidas nas pesquisas.
- **Redução de vieses:** alternância das alternativas de resposta para reduzir possíveis influências na escolha dos participantes.
- **Governança de insights:** organização das pesquisas e apoio à análise das informações.
- **Privacidade:** indicação de cuidados com a LGPD durante o processo de pesquisa.
